Step-by-step guide to run everything on this PC without Docker (database, API, gateway, ngrok,
admin portal, charger console), with every command and a troubleshooting table:
  docs/running-locally.md

Phase 0 status, test plan and decisions: see docs/phase-0/README.md
Phase 1 status: see docs/phase-1/README.md

The repository has four apps:
  plugev-api     core API (users, roles, networks, stations, chargers, live status) - NestJS + PostgreSQL. See plugev-api/README.md
  plugev-server  charger gateway (OCPP 1.5/1.6 SOAP and 1.6J) - Phase 0 PoC, MongoDB
  plugev-admin   new admin portal (users, stations, chargers, QR stickers, live status) - React + TypeScript. See plugev-admin/README.md
  plugev-portal  Phase 0 portal (old template + charger test console), being replaced by plugev-admin

Run everything with Docker (needs Docker Desktop):
  copy compose.env.example to .env, fill in the three secrets, then:
    docker compose up -d --build
  admin portal http://localhost:8080 | API http://localhost:4000/api/docs | gateway http://localhost:3003
  Phase 0 portal (charger console) http://localhost:8081
  Create the first Super Admin:
    docker compose exec api node dist/cli/create-super-admin.js --email you@example.com --name "Your Name"
  Emails (invitations, password resets) are not sent yet: find the links with
    docker compose logs api


Admin portal without Docker

1. Start plugev-api (plugev-api/README.md) and create a Super Admin with npm run seed:super-admin.
2. cd plugev-admin, then npm install and npm run dev.
3. Open http://localhost:3000 and sign in. The first sign-in sets up two-step verification.


Server SOAP (Back end / charger gateway)

1. cd plugev-server
2. Copy .env.example to .env and set MONGODB_URI (never commit .env).
   If the ngrok URL will be public, also set API_KEY.
3. 'npm install', then 'npm run dev' to start the server.
4. 'npm test' runs the automated tests (no database needed; it uses an in-memory MongoDB).

The server listens on port 3003 for everything: the portal API, OCPP 1.5/1.6 SOAP chargers and
OCPP 1.6 JSON (WebSocket) chargers. Port 3002 is also kept open for JSON chargers that were
configured with it before.


Plug EV Client (Front end)

1. cd plugev-portal
2. Copy .env.example to .env. If the backend has API_KEY set, put the same value in REACT_APP_API_KEY.
3. 'npm install --force' (default npm install might not work due to package conflicts),
   then 'npm start'. If the new admin portal is already on port 3000, accept the offer to use another port.

The "Charger Station Information" page is the charger test console: live status, all remote
commands, sessions, OCPP message log and the Phase 0 checklist.


Exposing the server to chargers (ngrok)

Install ngrok on the machine that runs the project:
(https://dashboard.ngrok.com/get-started/setup/windows)

Register your auth token on the machine (the command is on that page; the token is in the
'Your Authtoken' section on the left sidebar). ngrok may ask you to attach a bank card; there is
no charge for this usage.

Then follow plugev-server/commands.txt to start the tunnel and configure the charger. The ngrok URL
can change each time ngrok restarts, so update the charger settings accordingly.

No charger at hand? Run a simulated OCPP 1.6J charger:
    cd plugev-server
    npm run simulate -- --url ws://localhost:3003/ocpp/SIM-001
