Phase 0 status, test plan and decisions: see docs/phase-0/README.md
Phase 1 status: see docs/phase-1/README.md
Phase 2 and 3 status: see docs/phase-2/README.md and docs/phase-3/README.md

The repository has four apps:
  plugev-api     core API (users, roles, networks, stations, chargers) and the charging module chargers connect to
                 (OCPP 1.5/1.6 SOAP and 1.6J, port 3003) - NestJS + PostgreSQL. See plugev-api/README.md
  plugev-server  Phase 0 charger gateway (MongoDB) - replaced by the API's charging module, to be removed
  plugev-admin   new admin portal (users, stations, chargers, QR stickers, live status) - React + TypeScript. See plugev-admin/README.md
  plugev-portal  Phase 0 portal (old template + charger test console) - replaced by plugev-admin, to be removed

Run everything with Docker (needs Docker Desktop):
  copy compose.env.example to .env, fill in the three secrets, then:
    docker compose up -d --build
  admin portal http://localhost:8080 | API http://localhost:4000/api/docs | chargers http://localhost:3003/ocpp/<Charger ID>
  The Phase 0 gateway and portal only start with: docker compose --profile legacy up -d --build
  Create the first Super Admin:
    docker compose exec api node dist/cli/create-super-admin.js --email you@example.com --name "Your Name"
  Emails (invitations, password resets) are not sent yet: find the links with
    docker compose logs api
